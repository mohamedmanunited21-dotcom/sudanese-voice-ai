# استوديو الصوت السوداني الذكي | Sudanese Voice AI Studio 🎙️🇸🇩

تطبيق ويب متكامل لتحويل النصوص العربية (الفصحى أو العامية) وهندسة مخارج الحروف والتشكيل الصوتي بدقة، وتوليد نطق صوتي باللهجة السودانية الدارجة (لهجة الخرطوم والوسط).

## ✨ المميزات الرئيسية
1. **مُهندس النصوص الصوتية (Phonetic Normalizer):**
   - تحويل التراكيب والمفردات الفصحى إلى عامية سودانية أصيلة.
   - إبدال حرفي إجباري (القاف إلى `گ`، الثاء إلى `ت/س`، الذال إلى `د/ز`، الظاء إلى `ز/ض`).
   - تسكين أواخر الكلمات، وكسر حروف المضارعة، وضبط الشدة والمدود وهندسة الوقفات التنفسية.
2. **محركات توليد الصوت (TTS):**
   - **محرك مجاني غير محدود (Edge Neural):** بأصوات عربية طبيعية وتعديل السرعة وطبقة الصوت.
   - **محرك Gemini Audio TTS:** توليد صوت سريع بمفتاح Gemini.
   - **محرك ElevenLabs API:** اختياري لأعلى دقة.

## 🚀 كيفية التشغيل محلياً
```bash
# تثبيت محرك الصوت المجاني وأداة استخراج المقاطع
pip install edge-tts yt-dlp

# تشغيل السيرفر
node server.js
```
ثم افتح المتصفح على: `http://localhost:3000`
